Rate Limiter Test

This page demonstrates endpoint-specific rate limiting using express-rate-limit and rate-limit-redis.

How it works: You can make only 1 API request every 3 seconds to the same endpoint.

If you click the same button more than once within 3 seconds, you'll receive a 429 Too Many Requests error.

However, you can still call different endpoints without waiting!
